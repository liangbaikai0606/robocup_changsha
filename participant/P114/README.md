# P114 · 局部观测下的多机器人协同覆盖

> 2026 年 RoboCup 长沙邀请赛选拔赛（HNU-BigHeroX）参赛方案。
> 3 台机器人在**只看得到 0.6 米以内**的条件下，协同覆盖移动目标圈，同时避免相撞。

**公开套件：225.00 分 · 8 局全部完成 · 碰撞 0**
**300 个随机种子脚本配对分：170.16（主种子 20261003）；新种子 20261102 上 173.41，95% 区间 [160.28, 186.55]**
**与"规则+固定开车"这一族上界的差距：约 2.4 分**（不是整个任务的上界，见「已知局限」）

---

## 一句话

每台车独立决策：可见空圈按**自己的截击步数**排序，可见队友至少快 1 步就让；开车用 `a = clip(20·Δp + 4·(v̂_T − v_R), −1, 1)`；只在预测净收益 ≥ 0.05 时才和队友对撞借力。

## 任务

- 3 台车，动作是二维连续力，限幅 `[-1, 1]`，带阻尼和质量。
- 每台车只能看到自己周围 0.6 米：目标圈、队友、全是相对坐标，**不共享状态**。
- 目标圈会移动，官方不给速度，只能连续两帧差分估计。
- 评分 = 覆盖收益 − 碰撞惩罚。

## 方法

1. **选圈**：看得见的空圈，按自己的截击步数升序；可见队友比我快 ≥ 1 步就让，否则编号小的先。
2. **开车**：`a = clip(20·Δp + 4·(v̂_T − v_R), −1, 1)`，`v̂_T` 是连续两帧差分。
3. **速度估计**：看不见目标后最多外推 6 步，`reset()` 必须清空。
4. **借力对撞**：中心距 ≤ 0.16、互为最近车、有共同可见的远圈、弹开后各自还能进圈、且模拟剩余时间后净收益 ≥ 0.05 —— 五条同时成立才触发。

## 实验方法

这部分是这份方案真正的重点。

- **70 条实验**记录在 `experiments.csv`，每条含问题、改动、测试目录、结论、处置（保留/撤回）。
- **配对设计**：同一批种子下比较两个版本，消除场景难度差异。
- **bootstrap 置信区间**：300 个种子重采样，报 95% 区间；区间跨 0 的改动一律不采纳。
- **消融**：拿掉让圈 −1.36、拿掉 PD 第二项 −2.71，区间都在 0 以下；拿掉截击步数 −0.71，区间跨 0 → 保留但不宣称有效。
- **上界估计**：固定分配 oracle 枚举 6 种分配 × 5 个提前量，实跑 30000 个候选回合，得 167.54；再给"知道真实未来轨迹"的版本，约 172.6。→ **局部观测下还能追的分只有 ~2.4**，所以停止调参，转去写清楚局限。

这种"先估上界、再决定停不停"的做法，比特调参数更能说明一个策略是否到头了。

## 已知局限

- 公开套件只有 8 局，**不能作为泛化证据**。
- 300 个种子里有 92 个低于 100 分，最低 0 —— 长尾还在，拿掉任一模块都消不掉。
- 上界的 oracle 用了全局状态，是诊断对照，不是合法策略，也不是数学上界。
- 没做端到端学习，`method_type = rule`，`policy.npz` 未使用。
- **那 2.4 分不是任务的天花板，只是这条规则路线的天花板。** 在没参与调参的新种子上，另有三份公开提交和我放在同一把尺子上比较：其中一份用局部在线搜索，比我高约 2.8 分（覆盖多约 2.2、碰撞少约 0.7）。我做过一版轻量搜索（`mypath/local_search_e065.py`，随机射击与 CEM），12 个种子上区间跨 0，没有接进 `entry.py`。所以"接近上界"必须带限定词：**在这族策略里到顶了，出了这族还差一截。**

## 为什么值得一看

一个大一学生，在一个只有局部观测的多智能体任务上，把"改哪、为什么改、改完有没有用、什么时候该停"全写清楚了 —— 包括**自己算出还剩多少分可追**，以及**知道自己的上界外面还有一条路**。这比分数本身更难。
